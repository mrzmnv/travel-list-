# Travel List

A packing list app where you can add items, mark them as packed, and track your progress before a trip.

Built while learning React — based on a course project.

## What I practiced
- useState for managing list data
- Controlled forms
- Lifting state up between components
- Derived state and computed values

## Tech
- React 18
- Create React App

## Run locally

```bash
npm install
npm start
```
